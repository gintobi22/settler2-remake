# Settlers II Remake

A browser-based remake of **The Settlers II** built with React and HTML5 Canvas — no build step required.

🎮 **[Play it live on GitHub Pages](https://gintobi22.github.io/settler2-remake/)**

---

## About

This project recreates the classic city-building / real-time strategy gameplay of The Settlers II directly in the browser using React for UI and Canvas for rendering. It runs entirely client-side with no server or build toolchain needed — just open `index.html`.

## Features (current)

- Isometric tile map rendering with terrain types (grass, water, mountains, forest)
- Building placement system (woodcutter, sawmill, quarry, mine, etc.)
- Road and flag network for resource logistics
- Worker/carrier figures that transport goods along roads
- Resource stockpile tracking (wood, stone, food, tools, gold)
- Building construction queue and upgrade system
- Scrollable/zoomable map with mouse and keyboard controls
- Right-click context menus for flags and buildings
- Status bar with live game stats

## Running locally

Simply open `index.html` in a browser — no installation or build step needed. All dependencies (React 18, Babel) are loaded from CDN.
